How it works

A reproducible forecasting pipeline

Raw files stay local. Code, checks, reports and the compact dashboard are versioned on GitHub.

  1. 01Collect

    AEMO five-minute dispatch data, ERA5 weather and official NSW holidays.

  2. 02Prepare

    Aggregate to half-hours, validate continuity and build calendar features.

  3. 03Learn

    Compare baselines, ridge regression and gradient boosting chronologically.

  4. 04Test

    Hold out 2025 and report MAE, RMSE, MAPE and daily peak error.

Built as a reproducible electricity-demand forecasting project.
